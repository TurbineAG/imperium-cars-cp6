# IMPERIUM — Exotic Car Rental

Projeto acadêmico CP6 — Web Development (React + Vite + Tailwind CSS).

## Tecnologias
- React
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React

## Executar localmente
```bash
npm install
npm run dev
```

## Gerar build de produção
```bash
npm run build
```

## Páginas e componentes
- `src/pages/Home.jsx`
- `src/pages/Carros.jsx`
- `src/components/Navbar.jsx`
- `src/components/Footer.jsx`
- `src/components/CarCard.jsx`
- Rotas definidas em `src/App.jsx`
